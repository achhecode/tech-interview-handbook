## What does a typical CI/CD pipeline look like?

Medium
{: .label .label-yellow }

**Answer**

Commit, build, unit tests, static analysis, package (Docker image), integration tests, deploy to staging, smoke tests, deploy to production (rolling, blue-green or canary), with monitoring and automatic rollback.
