## What changed between Java 9 and Java 11?

Medium
{: .label .label-yellow }

**Answer**

| Version | Highlights |
|:--|:--|
| 9 | Module system (JPMS), `List.of/Set.of/Map.of`, private interface methods, JShell |
| 10 | Local-variable type inference with `var` |
| 11 (LTS) | Standard `HttpClient`, `String.isBlank/strip/lines/repeat`, `var` in lambda parameters, run single-file source with `java File.java` |
