## What are the notable features from Java 22 to 25?

Medium
{: .label .label-yellow }

**Answer**

Verify against the official release notes for your exact JDK build.

| Version | Highlights |
|:--|:--|
| 22 | Unnamed variables and patterns (`_`), Foreign Function and Memory API (final) |
| 24 | Stream Gatherers, Class-File API (final) |
| 25 (LTS) | Scoped values, flexible constructor bodies, compact source files with instance `main`, module import declarations, compact object headers |

Structured concurrency was still a preview feature in Java 25.

## Which Java versions are LTS?

Easy
{: .label .label-green }

**Answer**

Java 8, 11, 17, 21 and 25. Production systems usually move from one LTS to the next.
