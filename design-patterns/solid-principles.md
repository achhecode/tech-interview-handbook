## Explain the SOLID principles.

Medium
{: .label .label-yellow }

**Answer**

- **S**ingle Responsibility: a class has one reason to change.
- **O**pen/Closed: open for extension, closed for modification.
- **L**iskov Substitution: subtypes must be usable wherever the base type is expected.
- **I**nterface Segregation: many small interfaces beat one fat interface.
- **D**ependency Inversion: depend on abstractions, not concrete classes (what Spring DI enables).
