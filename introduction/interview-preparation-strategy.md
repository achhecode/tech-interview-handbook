## How should I prepare for a senior Java backend interview in four weeks?

Medium
{: .label .label-yellow }

**Answer**

Split the time by interview weight, and revise by topic rather than by random question.

| Week | Focus |
|:-----|:------|
| 1 | Core Java, collections, concurrency, Java 8+ features |
| 2 | Spring, Spring Boot, SQL, JPA/Hibernate |
| 3 | Microservices, design patterns, system design |
| 4 | Coding practice, mock interviews, project narrative |

**Key points**
- Solve 1 to 2 coding problems every day, and keep a "mistake log" of what you got wrong.
- Practise answers out loud; explaining aloud exposes gaps that reading hides.
- Research the company's stack and prepare 3 questions for them.

{: .tip }
Prepare your project story first. Almost every interview round comes back to it.

**Follow-up questions**
- How do you stay up to date with new Java releases?
- What was the last new thing you learned, and how?
